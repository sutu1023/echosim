# Spec Delta

## ADDED Requirements

### Requirement: 样例图能读出整份报告的主体、事件与行动

证据图谱面板 SHALL 让用户在武大 25 页报告的新图上直接浏览报告中的主要事件、相关方和具体行动。节点标签 MUST 显示足以识别具体主体的名称，MUST NOT 用分块首段文本或固定长度截断把不同主体显示成正文片段；画布空间不足时允许换行或省略显示，但悬停标题与详情 MUST 给出完整名称。

关系边 MUST 显示方向与动作标签。点选同一主体节点时，详情 MUST 列出该节点参与的材料关系，包含来自不同页面的关系及各自来源；用户 MUST 能从一个节点看到它在不同页的行为，而不是只看节点自身摘要。旧 build 没有新语义字段时，页面 MUST 继续可打开并按既有方式显示，不推断动作性质。

#### Scenario: 从新图读出主要事件与相关方

- **WHEN** 新图最终快照包含报告中的机构、当事方、事件与行动
- **THEN** 画布显示可区分的主体节点与带方向的行动关系
- **AND** 用户无需打开每条关系即可从标签与方向读出谁对谁做了什么

#### Scenario: 一个节点看到跨页的不同关系

- **WHEN** 同一主体在不同页参与不同关系
- **THEN** 画布只显示一个该主体节点
- **AND** 点选该节点后，详情列出其参与关系及各自页码与原文来源

#### Scenario: 旧图仍可对照打开

- **WHEN** 用户打开旧 build `f4c9a593-aa36-49e3-84cf-125ccaa88c21`
- **THEN** 页面正常显示旧节点、边与来源，不因缺少新语义字段而报错
- **AND** 旧图不被改写，可与新图分别查看

### Requirement: 关系详情显示读回事实、支持原句与来源性质

关系详情 SHALL 把一条边展示为“起点主体—动作—目标主体”，并显示服务端返回的来源性质与图谱服务读回的事实描述。`media_report`、`party_claim`、`official_decision` 与 `other_material` MUST 分别显示为“媒体报道”“当事方主张”“机构正式决定”“其他材料陈述”。详情 MUST 列出该关系的材料来源；每条来源 MUST 显示材料名称、PDF 物理页码或文本段落、支持原句，并复用既有原文定位能力打开原件或高亮原文区间。来源打开 MUST 保留当前 `layout`、`lang`、`buildId` 与项目上下文。

`party_claim` 与 `media_report` MUST NOT 被显示为“已证实”“机构正式决定”或同等确定性表述。只有来源性质为 `official_decision` 的关系才可显示“机构正式决定”。旧快照没有 `claimNature` 时，详情 MUST 不显示具体性质，也不默认成机构正式决定或已证实。

#### Scenario: 关系详情回到支持该说法的原句

- **WHEN** 用户点选一条材料关系
- **THEN** 详情显示起点主体、动作、目标主体、来源性质、事实描述、支持原句、材料名称与页码或段落
- **AND** 点击来源后打开正确原件位置并保留 `layout`、`lang`、`buildId`

#### Scenario: 当事方主张不被显示成事实

- **WHEN** 用户点选一条 `party_claim` 关系，其支持原句为“某方称……”
- **THEN** 详情显示“当事方主张”，并展示该原句与材料位置
- **AND** 不显示“已证实”“机构正式决定”或同等确定性标签

#### Scenario: 建议撤销不被读成已经撤销

- **WHEN** 报告作者建议撤销某项处分，而材料没有显示校方已作出撤销决定
- **THEN** 页面不得把该建议显示成校方已经撤销处分
- **AND** 页面保留建议者与建议内容

### Requirement: 画布箭头与标签准确表达原文角色

工作台 SHALL 按最终边类型与方向显示关系文字。平台行动边 MUST 读成“用户在平台上行动”，不得读成“平台向用户行动”。转述关系 MUST 在画布上显示“部分账号/转述者 + 传播/转述 + 报告所称对象”，目标节点 MUST 带“报告所称/未证实”限定。报告建议边 MUST 显示“报告建议”性质，并保留“建议”语义的动作标签。关系详情 MUST 与画布使用同一条准确句子，不得只在详情中修正而画布仍显示错误方向或已发生事实。

#### Scenario: 画布直接读出女性用户维权

- **WHEN** 平台行动边方向为“女性用户 → 小红书”
- **THEN** 画布标签与关系详情读成“女性用户在小红书上维权”
- **AND** 不出现“小红书向女性用户维权”

#### Scenario: 画布保留不实信息限定

- **WHEN** 用户查看“部分账号传播报告所称不实信息”的关系
- **THEN** 画布目标节点显示“某事件（报告所称，未证实）”
- **AND** 关系详情不把该说法显示为已发生事件

#### Scenario: 画布区分报告建议与机构决定

- **WHEN** 用户查看第 22 页匿名评审关系
- **THEN** 画布与详情显示“报告建议”
- **AND** 边标签保留“建议”语义
- **AND** 已作出的校方处分仍显示“机构正式决定”
