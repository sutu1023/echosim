# Design

## Context

动机与范围见 proposal.md。当前 api/app.py 只有健康、首页与条件注册的开发模型诊断；adapters/postgres.py 仅 SELECT 1；worker 没有业务任务；frontend/src/main.tsx 仅区分首页和模型测试页。没有账号、迁移或作品实体。现有 PostgreSQL、同域前后端、错误格式和分层规则可以复用。

这是跨 HTTP、存储、会话和页面的首次业务能力，须先补规约失败用例。现有领域词已足够，无新增术语；技术选择可局部替换，不新建 ADR。

认证用例已按规模拆出至 `2026-11-13-user-auth`；以下第 2–4 节保留联合设计上下文，归属此前置变更。作品与整体集成归属本变更。

## Goals / Non-Goals

**Goals:** 让所有作品操作经过服务层身份与归属检查；让会话、密码重置和创建幂等在多进程与重启后保持一致；开发快捷登录复用同一会话路径。

**Non-Goals:** 不引入任务队列、模型调用、JWT、第三方身份系统、通用管理后台或创作工作区；轻量创建作品同步完成，不属于产品基线中材料处理/推演等持久后台任务。

## Decisions

### 1. 保持分层与显式组装

api 只校验 HTTP、cookie、CSRF 与响应格式；services 管账号/会话/作品用例；domain 定义数据与存储、密码哈希、时钟契约；adapters 实现 PostgreSQL 和密码算法；main 与账号命令为组装入口。服务不导入 FastAPI、psycopg 或适配器。授权查询同时包含 user_id 和 work_id，不能先取作品再由页面过滤。采用具体用例而非通用 CRUD 框架，减少越权入口。

### 2. 数据库会话与账号命令

新增 users、sessions、works、work_creation_requests、login_attempt_windows 与迁移版本记录。业务实体使用 UUID、UTC created_at/updated_at；works 带 user_id；创建幂等记录带 user_id、work_id、operation、request_key，并通过 work_id 关联规范化标题。用户账号名唯一，sessions 保存高熵随机令牌的摘要、user_id、expires_at；撤销通过删除会话记录实现，不保存原始 cookie。

采用数据库会话而非无状态 JWT，以直接撤销、七天固定期限与重启恢复为优先。密码重置与会话撤销在同一事务；登录签发与密码重置按用户行锁串行化，并在签发前确认已验证的密码版本未变化，避免旧密码并发登录逃过重置。快捷切换同样原子撤销旧会话、签发新会话，失败保留旧会话。

密码使用 Argon2id 库（拟 argon2-cffi，实施时锁定可用版本并审计），优于自行实现密码学。命令通过隐藏交互或受控标准输入接收密码，不接受密码命令行参数；不提供默认密码。账号输入的实现默认值：用户名为 3–64 位 ASCII 字母、数字、下划线或短横线并转小写；密码为 12–128 个 Unicode 码点且不 trim。用例测试覆盖边界。体验账号由显式开发初始化命令幂等创建，不覆盖既有密码或作品，不在应用启动时暗中插入。

### 3. 同域 HTTP 契约与保护

拟定接口：POST /api/v1/sessions（登录），GET /api/v1/sessions/current（身份及会话 CSRF 数据），DELETE /api/v1/sessions/current（退出），POST/GET /api/v1/works，GET /api/v1/works/{id}。错误沿用 error.code/message/request_id；添加 401、403、409、429 的明确映射，数据库不可用返回安全 503 而非伪装成登录失败。

cookie 使用 HttpOnly、SameSite=Lax、Path=/，有效期七天，production 强制 Secure。仅 development/test 本地 HTTP 验证允许不设 Secure；实现时在 security.md 写明环境限定及生产 cookie 测试作为替代检查。前端不持久化令牌。会话写操作校验 X-CSRF-Token 与可信 Origin；首次登录及快捷登录无需已登录 token，但必须是 JSON、准确同源 Origin，不接受跨源或缺失 Origin。不信任任意 Host/转发头决定可信源：由部署配置指定前端 origin，生产须 HTTPS；所有写操作源校验失败返回 403。

限速采用数据库原子固定窗口，默认每用户名 15 分钟 5 次失败、每来源 15 分钟 30 次失败；达到阈值后的请求返回 429，窗口到期恢复，不无限锁定账号。不存在账号使用同类密码验证路径与同一限速策略。来源使用连接对端地址，仅显式配置可信代理时采用转发信息；限速记录不保存密码，过期窗口可清理。阈值是本轮实现默认值，测试使用可注入时钟验证边界，不实际等待。

### 4. 开发一键登录使用正常授权

APP_ENV=development 且 DEV_QUICK_LOGIN_ENABLED=true 才注册 POST /api/v1/dev-sessions，目标只接受 A/B 固定映射，不能传任意 user_id。默认关闭，production/test 即便开关为真也不注册入口；页面通过后端公共能力响应了解是否显示按钮，不以打包环境变量替代后端限制。公共响应不提供私有身份数据，禁用时直接请求入口为 404。

登录页提供 A/B 按钮，作品页可通过“切换体验账号”回到同一入口。点击后才原子切换，导航本身不退出；失败显示错误，保留当前身份。体验账号的作品持久保存；密码重置只撤销已有会话，显式开启的开发快捷入口仍能重新签发会话，这不改变它仅供本地验收的定位。

### 5. 原子创建与分页

Idempotency-Key 使用 UUID，由前端为一次明确的新建生成；数据库唯一约束 (user_id, operation, request_key)。创建作品与请求记录同事务，唯一冲突后读取已提交记录并比对规范化标题；同内容返回相同 201/作品，不同内容 409。对同键并发用数据库约束协调，不依赖进程内锁；事务失败整体回滚。

前端超时保留原键与已提交标题供重试，输入改变后明确按新建提交才换键。键仅保存在当前表单状态，不承诺浏览器关闭后自动恢复表单；API 持相同键重放在重启后仍可靠。

列表使用 (created_at,id) 游标倒序分页，limit 默认 20、范围 1–100；响应 items/next_cursor。游标是位置提示而非授权凭据，所有查询仍绑定当前账号；禁止任意过滤字段。标题 trim 后以 Unicode 码点计数，前端使用 Array.from 对齐 Python 语义，不进行 NFC 转换。详情与列表输出 id/title/created_at/updated_at，不暴露其他账号字段。

### 6. 页面与既有基线迁移

显式提供 /login、/works、/works/:id，直接导航或刷新由后端返回前端入口；未知页面和未知 API 继续 404，不使用无条件 SPA fallback。首页保留健康展示并加入登录/作品导航；详情明确故事准备尚未开放，不冒用 /prepare 承诺完整准备能力。保留 /dev/model-test 的既有开关与规约。

更新 backend/tests/test_runtime.py 与 scripts/smoke.py 的旧业务 404 断言为无会话 401、有效会话下不可访问资源 404；不是删除安全回归。实施时同步 product.md 的实现状态、standards/product.md 的页面范围、data.md 的业务表描述及追溯表，主规约只在后续同步/归档阶段更新。

## Risks / Trade-offs

- [首次业务纵切可能超过 500 行业务逻辑] → 实现前按模块估算并持续检查；超过规范阈值时拆分变更与依赖顺序，不默许例外或减少验收。当前文档定义完整验收目标。
- [快捷登录被误带到线上] → 双重启用条件、固定账号映射、禁用环境 HTTP 测试；测试不能只断言按钮隐藏。
- [代理来源影响限速] → 明确信任配置，默认不读转发头；来源聚合可能限制共享代理，保留独立用户名阈值并记录限制。
- [重置与并发请求竞态] → 对会话签发和重置用事务串行化；已经完成鉴权并开始执行的请求不承诺被追溯撤销，重置完成后的新请求必须拒绝旧会话。
- [新增密码哈希依赖及 cookie 环境差异] → 锁文件、make audit、生产配置测试；本地证据不当作公网验证。

## Migration Plan

1. 新增编号 SQL 迁移与版本表，迁移事务及数据库锁保证重复执行安全；迁移通过显式命令执行，API 不自动修改 schema。已有业务迁移文件不得改写。
2. 先在独立数据库验证空库迁移、重复执行、失败回滚，再启动应用；API 启动前检查必要业务 schema，缺失则以安全配置错误退出；不改变健康端点既有数据库探针语义。
3. 用账号命令预置验证用户，单独开启本地快捷登录；现有健康/模型诊断回归后进行双账号验收。
4. 回退到旧应用版本可保留新增表；不删除用户作品或正常开发卷。需要修复 schema 时新增向前修复迁移。
5. 本轮不部署公网。正式持久数据上线前仍须按 operations.md 配置备份并演练恢复；本地迁移/重启通过不代表备份目标达成。
