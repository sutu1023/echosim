# Proposal

## Why

当前 `/` 直接承载私有项目列表：访客看到的第一个页面是登录跳转，登录后也没有一个稳定的“从哪里开始”的入口。随着材料、角色、运行、报告与互动阶段即将进入产品，EchoSim 需要一个公开的中文控制台说明整体推演路径，并按项目与阶段提供可直接打开、可切换视图的工作台外壳，避免后续能力各自发明导航与地址。

## What Changes

- 新增公开中文控制台并放在 `/`：左栏展示系统状态与五个阶段（构建证据图谱 → 准备角色与环境 → 双平台运行 → 生成报告 → 深度互动），右栏提供材料入口、推演问题与“开始”主按钮；访客可打开控制台，但进入真实项目仍需登录。
- 明确“我的项目”的私有地址为 `/projects`：把现有项目列表从 `/` 迁出，登录默认落点改为 `/projects`；`/projects/:projectId` 与 `/history` 保持私有，历史与详情链接继续可用。
- 定义“开始”在三种身份/数据状态下的确定行为：访客先登录再进入私有项目列表，已登录且无项目进入创建入口，已登录且已有项目进入最近创建项目的第一阶段。
- 新增按项目与阶段可深链接的工作台：`/projects/:projectId/workbench/:stage`，五个阶段拥有稳定英文 slug；工作台共用顶部工具条，支持「图谱」「双栏」「工作台」三种布局与中英文切换。
- 布局与语言写入 URL 查询参数（`layout`、`lang`），刷新、复制地址与浏览器前进后退时保留当前项目与阶段；刷新不回到首页，切换布局或语言不丢失阶段。
- 为五个阶段声明进入条件：直接打开缺少前置数据的阶段时，页面说明缺少什么、可以去哪里继续；当前版本不得伪造材料、运行结果或报告。
- 统一工作台的加载中、空数据、错误与正常四态，明确区分“还没有材料”和“服务暂时不可用”；匿名访问、他人项目、不存在项目、非法阶段与数据库不可达各有确定表现。
- **BREAKING**：`/` 不再是私有项目列表，而是公开控制台；依赖“访问 `/` 必然进入项目列表或登录页”的旧行为需要改为 `/projects`。
- 扩展验收：`make verify` 增加控制台与工作台深链接的服务端可验证断言，保留 Change 01/02 的首页、健康故障恢复、进程身份、账户隔离、401/404/503 与连续执行场景；布局、语言、截图与浏览器后退仍由人工走查记录。
- 更新 `README.md` 的路由、页面与人工走查说明，并在 `AGENTS.md` 补充新的公开/私有地址边界（若验收规则发生变化）。

## Capabilities

### New Capabilities

- `guided-console`: 公开中文控制台的内容结构、系统状态、五阶段说明、材料/问题入口、主按钮三态行为与桌面双栏可见性。
- `project-workbench`: 按项目与阶段深链接的工作台外壳、共享工具条、三种布局、中英文切换、阶段进入条件、四态与导航保持规则。

### Modified Capabilities

- `project-isolation`: 页面入口与可见性从“`/` 即私有项目列表”改为“`/` 为公开控制台、`/projects` 为私有列表”；登录默认落点、登录后返回原地址、详情/历史链接与工作台私有路由的未登录/他人/不存在表现需要重新声明。
- `reproducible-verification`: 验收场景增加公共控制台与五条工作台深链接的服务端可访问性断言，并明确浏览器布局走查不写入 `make verify` 报告，同时保留 Change 01/02 全部回归场景。

## Impact

- 前端：`web/src/router.ts` 路由表与守卫、`App.vue` 顶层导航、项目列表/详情/历史页链接、新增控制台与工作台视图、共享工具条、阶段注册表、布局与语言状态、错误与空态组件、`styles.css` 的桌面双栏与三栏布局。
- 接口：不新增后端业务接口，复用 `GET /health`、`GET /api/auth/session`、`GET /api/projects`、`GET /api/projects/{id}`；现有 401/404/503 契约保持不变。
- 验收：`scripts/verify.py` 增加路由可达性与既有回归断言；`docs/acceptance/` 在实施后新增浏览器走查记录与 1280×720、1440×900 两种尺寸截图，本规约阶段不创建验收记录。
- 文档：`README.md` 路由表、登录落点、控制台与工作台说明、人工走查步骤；`AGENTS.md` 的地址边界与验收规则。
- 数据与迁移：不新增数据库表、不修改迁移，不需要新配置项；材料入库、后台任务、真实推演与案例回放明确不在本次范围。
