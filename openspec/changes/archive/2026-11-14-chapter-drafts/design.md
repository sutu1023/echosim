# Design

## Context

现有 Adoptions.choose / run 对整次原始推演校验并提交。新流程还要支持创作者在采纳前审阅修改稿产生的事实。原始推演继续作为可回看的历史。

## Goals / Non-Goals

覆盖单次推演成章、修改稿采纳、按已采纳版本续演，以及已采纳章节的措辞润色。跨轮改史、合并多次推演成章与部分采纳均在范围之外。

## Decisions

章节绑定作品与推演。生成任务绑定来源版本和模型配置，正文按进度返回，完成后保存首稿。重新生成写入候选版本；显式替换时检查原稿版本及推演状态。已采纳后成章以该轮正式事件为依据，润色保存前也须检查事实一致性。

修改稿采纳分为准备和确认。后台任务从已保存的整篇修改稿提取有正文依据的事件、事实变化及可见角色记忆，与本轮开始时的设定和主线校验，向创作者展示关键变化。最终确认绑定同一份预览、正文版本和主线版本。沿用采纳事务一次提交正式事件、记忆、事实与采纳状态。证据引用固定的采纳文本版本，之后的润色不会改变引用。没有章节时沿用直接采纳入口。

## Risks / Trade-offs

模型可能沿用原推演中的旧收件人或把角色猜测写成事实。以修改稿中的证据和可见性校验每个正式事件及其派生事实。提取有歧义时保留草稿并说明冲突。晚到的生成结果、重复确认和并发保存均须在写入时复核归属、状态与版本。
