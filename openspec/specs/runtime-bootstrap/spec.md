# runtime-bootstrap Specification

## Purpose

让任何人从干净克隆用一条命令在 `127.0.0.1:8080` 得到可用的 EchoSim 同域入口，并能可靠地停止与再次启动，作为后续所有功能的可复现底座。

## Requirements

### Requirement: 一条命令完成本地启动

从干净克隆出发，项目 SHALL 仅通过 README 记录的配置步骤与 `make up` 完成前端、后端与数据库的构建和启动，并在首页可访问后才以退出码 0 结束。

#### Scenario: 干净克隆首次启动

- **WHEN** 在干净克隆中按 README 执行 `make up`，且本地不存在 `.env`
- **THEN** 命令从 `.env.example` 生成 `.env`，构建并启动全部服务，且在 `http://127.0.0.1:8080/` 可访问后以退出码 0 结束
- **AND** 任一服务启动失败时命令以非零退出码结束并输出可定位的失败原因

#### Scenario: 重复启动不产生冲突

- **WHEN** 在服务已运行的情况下再次执行 `make up`
- **THEN** 命令以退出码 0 结束，不产生重复容器或端口占用错误，首页与健康检查保持可用

### Requirement: 同域提供首页与健康检查

应用 SHALL 在同一个 origin（相同协议、主机与端口）上提供首页与 `GET /health`，使浏览器无需任何跨域配置即可读取健康状态。

#### Scenario: 浏览器看到 EchoSim

- **WHEN** 在浏览器或 HTTP 客户端访问 `http://127.0.0.1:8080/`
- **THEN** 返回 200 与 HTML 文档，正文包含产品名 `EchoSim` 与描述“材料驱动的双平台推演工作台”
- **AND** 该文档引用的构建产物均可从同一 origin 成功获取

#### Scenario: 健康检查与首页同源

- **WHEN** 访问 `http://127.0.0.1:8080/health`
- **THEN** 请求与首页使用相同协议、主机和端口，页面脚本可直接读取该响应而无需跨域许可

### Requirement: 仅绑定回环地址

本地服务 SHALL 仅发布在回环地址 `127.0.0.1:8080`，不得默认暴露到局域网或公网接口。

#### Scenario: 端口不对外暴露

- **WHEN** 服务启动完成后检查宿主机端口绑定
- **THEN** 8080 端口仅绑定在 `127.0.0.1` 上，非本机来源无法直接连接

### Requirement: 可重复的停止与再启动

项目 SHALL 提供一条停止命令，结束并移除应用与数据库运行实例、释放端口，同时允许随后再次启动成功。

#### Scenario: 停止后再次启动

- **WHEN** 执行 `make down`
- **THEN** 应用与数据库容器及其网络被停止并移除，`127.0.0.1:8080` 被释放
- **AND** 随后执行 `make up` 能再次成功启动，无需人工删除数据卷或清理残留容器

### Requirement: 配置样例自解释

项目 SHALL 在 `.env.example` 中列出启动所需的全部配置项、非敏感默认值和用途说明，且不得包含真实凭据。

#### Scenario: 无本地配置也能启动

- **WHEN** 全新环境只有仓库内容、尚未手工创建 `.env`
- **THEN** 使用 `.env.example` 中的默认值即可完成启动，README 说明各配置项含义与覆盖方式
- **AND** `.env.example` 中的密码、密钥等字段仅为明显的开发占位值，不指向任何真实环境
