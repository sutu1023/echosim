# 产品基线

EchoSim 面向个人小说创作者，通过有来源和角色可见性约束的推演，帮助用户将故事设定推进为可以编辑和逐章采纳的正文。与单轮聊天相比，保留独立角色、正式剧情、材料来源与可恢复查看的推演历史。输出是可能剧情，不承诺完整长篇质量。

## 创作流程与能力

创建作品 → 导入材料 → 补全并确认设定 → 实时推演 → 生成并编辑章节 → 校验采纳 → 继续推演。

| 编号 | 规划能力与验收边界 |
| --- | --- |
| P01 | 预置账号用户名密码登录，无公开注册；用户之间作品、材料、角色、任务与章节隔离，跨账号请求与不存在资源均为 404。 |
| P02 | 导入 MD、TXT、文字型 PDF 并预览；拒绝扫描件、加密或不可靠解析的 PDF。 |
| P03 | 提取或补全概要、世界规则、大纲、角色卡；区分材料依据与新增设定，用户确认后生效。 |
| P04 | 轻量 GraphRAG：实体与关系、有限跳数扩展、原文片段和向量检索；保留来源、顺序、作品和角色可见性。 |
| P05 | 表单修正别名与关键关系；局部人物关系图查看来源，不做完整图编辑器。 |
| P06 | 正式角色有独立目标、记忆和行动；架构智能体管理场景与顺序，不能改写确认设定和正式剧情，不能自动增加自主角色。 |
| P07 | 有限轮次推演；校验后逐条展示行动、对白和事件；停止完成当前事件后退出；页面断开不终止任务，重连补取事件。 |
| P08 | 推演结束或停止后手动生成章节；正文流式输出，可编辑并下载 Markdown；不改变重大事件。 |
| P09 | 采纳前重新抽取事件与记忆并检查冲突；明显冲突阻止采纳；采纳原子地进入唯一主线，不支持修改、删除或回退。 |
| P10 | 历史保留未采纳结果；仅已采纳章节作为后续正式剧情依据。 |
| P11 | 大纲补全、冲突推进、一致性检查三项技能支持启停和执行记录。 |
| P12 | 只读 MCP 提供故事检索、角色卡和确认状态读取；身份由服务端绑定，工具复用授权服务层。 |
| P13 | 用户配置生成模型和 embedding 模型的地址、名称与密钥；后端测试和调用，密钥加密保存、掩码回显，配置按用户隔离并版本化。 |

材料处理、设定准备、推演和生成采用持久后台任务：提交返回 202，状态可查询。同一作品仅允许一个修改故事状态的任务；重复提交不能重复生效。有限重试，失败保留已完成记录，不提供失败推演断点续跑。

## 规模与界面

四个工作区：作品列表、故事准备、推演现场、章节与历史；模型配置作为设置页面。桌面浏览器、中文界面与创作为主。默认 5 角色、10 轮；暂定最大 8 角色、20 轮；输入目标 30 万中文字、20 MB。这些是待实测目标，不是当前能力承诺。

## 不做

舆情分析、OCR、联网搜集材料、多人协作、作品社区、故事分支、回滚、已采纳章节修改、自动连载整本小说、运行中干预、移动端专项适配、多语言切换、全图社区发现与多层社区摘要。秘密边界依赖明确标记，不自动推断所有角色的知识。

| M0 规约与运行条件 | 工程骨架可复现，核心场景明确，实际模型调用及最小公网应用验证成功。当前骨架交付不代表 M0 完成。 |

| M4 稳定性与规模 | 停止、重连、重试、并发与重复提交验证通过，公布实测上限。 |
| M5 交付 | 公网闭环、可复跑门禁和定位明确的验证证据。 |

## 本轮实现：一句话创作与最小推演

按依赖顺序实现三个关联 change，真实运行证据见 docs/verification/ 对应记录：

1. `2026-11-13-persistent-model-config`：用户持久生成模型配置，沿用 OpenCode Go、默认 deepseek-v4.1-flash；验证后生效、密钥加密、版本绑定，embedding 延后。
2. `2026-11-13-generated-story-preparation`：一句故事创意自动生成概要、世界规则、简短大纲及三名角色；自然语言整版重写，用户整版确认。生成采用持久后台任务；确认是无模型调用的原子操作。
3. `2026-11-13-minimal-role-simulation`：已确认三名角色在单场景中推演三轮，校验后的行动、对白和结果逐条展示；支持停止、刷新补取、失败保留与跨用户隔离。

这一切片的角色数与轮次固定为 3/3，优先验证短场景；前述 5/10 默认与 8/20 上限仍为后续产品目标。候选设定不自动生效，新的确认不改写旧推演所引用的版本；模型配置更新只影响新任务。

联合完成条件是本地真实浏览器、真实模型跑通“持久配置→一句话生成→确认→剧情”，并有自动门禁和真实证据。材料、GraphRAG、章节生成与采纳、公网部署不在本轮；完成这些 change 仍不代表 M0/M1 完成。
