# 产品基线与里程碑

回响 EchoSim：面向学生与普通体验者，观察虚拟角色如何围绕真实新闻讨论、回应和改变观点。单人开发。新闻提供背景，不采集真实评论，不做真实预测。

## 首版流程与页面

新闻链接 → 提取预览（失败可粘贴正文并标明用户补充）→ 确认背景 → 生成/调整角色 → 启动 → 观看/取消 → 回顾 → 历史/分享。

固定侧栏全局新建、我的推演、说明；当前推演分背景、角色、讨论、回顾四区，URL可定位。手机完整流程，未生成分区显示空状态。分享可看确认背景摘要、角色、模拟发言和回顾，不公开原文、凭证和内部信息。

状态：草稿→就绪→推演中→生成回顾→完成；可进入正在取消、取消、失败。回顾事实降级为带警告完成，明确未生成AI解读；角色发言失败或总超时则失败。终结不改写，复制配置新建。一次免费流程从首次付费调用计次，准备与随后首次启动不重复计次；主动重跑为新流程。

## 路线

- M0：本轮。规范、OpenSpec、探针、配置、日志、容器、状态页与检查，不含业务模型或模型调用。
- M1：真实新闻、手动补充、背景确认、角色。仅样本验证过的明确域名开启自动提取，候选新华网和中新网；其余转手动。
- M2：确定性假模型、轮次/逐条SSE、取消、重连与引用校验。
- M3：DeepSeek、每轮短回顾和最终总结、20样例评测、预算、临时BYOK。不开放任意模型地址。
- M4：匿名历史、只读分享、删除与备份清理、公网HTTPS、蓝绿与恢复、独立试用。

无账号、长报告、文件导出、批量上传、干预分支、实时热点、真实评论或重型Agent框架。服务器和域名尚未申请，费用另行决定。

## 视觉

参考 https://echo.lubeiluchen.cc/ 的固定侧栏、纸感卡片、粗边框和偏移阴影；素材自行实现，不复制图片字体音乐。正文直白中文，状态可用少量英文标签。颜色、间距与组件集中定义。记录时间按浏览器时区，预算重置明确北京时间。
