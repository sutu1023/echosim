# 推演结果可直接采纳进入正式剧情

2026-11-14 的需求讨论决定允许创作者在推演任务结束后直接采纳其结果，使事件、角色记忆与故事图谱一致更新并成为后续推演的依据，不再以章节生成为前提。相较 ADR 0003 的章节唯一入口，这使创作者可以先通过连续角色互动推进故事，再整理正文；代价是后续章节能力必须处理其剧情已经采纳的情况，不能重复写入正式剧情。

本决策替代 ADR 0003 中“仅采纳章节”的限制，保留唯一主线、冲突检查、原子采纳与不可逆原则。前端只展示一张故事图谱，推演生成与播放期间不更新，用户采纳后才更新；未采纳推演保留为历史，不改变正式剧情。本文件记录已确认的设计方向，不代表采纳或图谱能力已实现。

只允许顺序推进：非空成功或主动停止的结果必须整次采纳或永久放弃后才能开始下一次；失败和空结果不可采纳。首次采纳后冻结故事设定，避免改写已发生剧情的基础；代价是首版不能在连续创作中修订设定。旧推演缺少主线版本绑定，保持只读且不自动采纳；本轮不提供分支或已采纳结果的回退。
