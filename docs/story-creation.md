# 一句话故事准备与角色推演

模型设置完成后，在作品详情进入故事准备。输入 1–2000 字创意，后台生成概要、世界规则、大纲和三名角色；通过自然语言意见整版重写，失败保留旧候选。内容标明为模型创作新增。确认具体当前版本后才允许推演；重复确认幂等，过时版本确认 409。候选与确认是两个独立指针，重新生成不会自动覆盖确认，旧推演保留原确认快照。

生成 API：POST `/api/v1/works/{id}/preparation-tasks`，提交 idea、可选 base_version_id 及 UUID Idempotency-Key，返回 202。GET `/preparations` 读取候选、确认与任务历史，POST `/preparation-confirmations` 提交 version_id/expected_candidate_id。GET `/tasks/{task_id}` 恢复任务状态。所有端点均核验作品及资源归属，写操作校验 Origin/CSRF。

推演 API：POST `/api/v1/works/{id}/simulations`，空对象请求体和幂等键；GET `/{simulation_id}`、`/events?after=N`、`/stream`；POST `/stop`。旧版历史最多九事件。当前推演由架构智能体按剧情选择角色，每次任务最多24事件。SSE ID 对应事件序号，支持 Last-Event-ID；前端有轮询补取与去重。会话失效后流关闭。每个角色的上下文只含公开设定、自己的秘密与可见事件；任务内已接受事件构成记忆，不写正式剧情。

同一作品最多一个 queued/running/stopping 任务。提交与配置引用同事务保存；模型调用在事务外。任务每五秒续租，租约三十秒，存活的 worker 在租约到期后十秒内回收失败任务；全部 worker 停止时将在恢复运行后回收。fencing 禁止旧 worker 写结果。失败任务不续跑，重试是新任务。停止 queued 不调用模型；停止 running 完成至多当前事件后 stopped，终态不可恢复。

每次模型调用 60 秒、最多两次重试，1/2 秒退避；准备总期限 240 秒，推演事件 240 秒、推演总期限 45 分钟。停止遇到模型失败则不发布未完成事件。记录模型、配置/提示版本、参数、耗时和可用 usage，不记录完整提示、密钥或私有正文。

迁移 003 新增任务与版本，004 新增事件。回退前停止领取，保留历史表，采用新增迁移修复。自动测试与真实模型评测独立记录；本轮整次采纳见下文。章节生成、公网及规模验证属于后续里程碑。

## 2026-11-14 动态叙事实现（验证进行中）

新推演保持三角色和单场景，调度依据当前局势选择下一行动者，可连续行动或旁观；目标12–18事件、最多24，允许阶段性提前结束。content.schema_version=2，segments按发生顺序区分narration/dialogue，每段独立visibility，对白speaker为行动者。正文目标200–400字、3–6段；非法引用、身份或知识使用不能持久化。旧action/dialogue/result在读取时适配，不改历史内容。

前端仅在整事件校验并保存后逐字播放，支持立即显示本事件/剩余剧情、回看不自动滚动、返回最新。刷新直接恢复完整旧文本，新到事件去重播放。后台planning/generating/validating阶段不含提示、推理或候选正文；播放速度不影响任务。新读取游标范围0–24，仍分页有界、逐资源授权。

## 整次采纳与当前图谱（2026-11-14 实现，联合质量验收进行中）

确认设定会持久排队构建初始图谱，模型调用不在确认事务内。构建期间不能启动推演；失败后在图谱区域重试。旧作品已有确认版本但没有初始图谱时，也在此构建。未确认时不生成虚假空图。

每次成功或主动停止且非空的推演都会等待整次采纳或永久放弃；等待期间不能生成另一轮或修改设定。采纳前明确确认不可逆；检查失败保持待决状态，可重试或放弃。采纳检查与事实提取在事务外，提交时一起写入事件引用、角色可见记忆、实体关系与主线版本。首次采纳后设定锁定，下一次推演绑定已采纳主线快照。失败或旧格式任务仅保留阅读。

前端只显示当前已接受主线的图谱，不跟随播放进度或历史选择。初始图谱和采纳事实来自确认规则、角色公开/私有字段及已通过校验的事件；创作者概要和未来大纲不是既成事实来源，也不传给角色。角色仅获取自身资料、其他角色公开资料、允许可见的事件和事实，创作者可以查看全部证据。

`GET /api/v1/works/{work}/story-graph` 返回 `state/version_id/canon_revision/content`；content 内为 entities、relations、sources，已终止关系保留但不作为当前边显示。来源文字包含在同一个经过作品授权的响应内，不提供裸 source_id 查询。`POST /story-graph/builds` 只重试当前确认版本；已就绪返回ready，构建在途409 WORK_BUSY，不能重复生成。采纳 `POST /simulations/{task}/adoptions` 必须带幂等键、期望主线版本和不可逆确认，返回202；放弃端点为 `/discards`。所有写请求均需 Origin 和 CSRF。

图谱支持缩放、拖动、方向键平移、适应画布、实体/关系文本列表和证据查看。读取失败保留旧图并显示可能过期提示；重试成功后整体替换。容量为100个实体、200条含历史关系，推演输入主线JSON超过60000字符会明确拒绝，当前不承诺任意长篇容量。

迁移005→006→007须按序应用。旧事件不改写，读取适配后显示动作和对白。回退前先停止接收新任务并排空新种类任务；保留新表和事件，不能将新任务交给旧worker或把24条数据强制改回9条约束。

推演调度依据已公开事件中的物品去向和已完成动作。角色公开坦白、拒绝或有条件交付后，受影响的角色可以用自己的行动回应。校验器检查无新原因的重复交付；主要选择已经产生可见后果时可自然结束，例行记录和等待不单独延长剧情。

## 章节与历史

从推演现场打开章节草稿，或在作品详情进入「章节与历史」选择推演记录。成功或主动停止且已有事件的推演可成章。生成时可阅读已返回的文字，刷新后能继续查看任务。修改标题、正文后点击「保存草稿」，下载的 Markdown 使用已保存版本。重新生成会先给出新稿预览，点击「替换原稿」才覆盖。

待采纳的草稿可以改变本轮行动。保存后点击「核对修改稿」，核对将进入主线的事件，再勾选确认并点击「采纳修改稿」。若提示与前史冲突，修改草稿后重新核对。下一轮使用确认版本的事件、角色记忆与图谱。未成章时可以直接采纳推演。已采纳的推演支持事后成章和措辞润色，放弃前已保存的章节可阅读和下载。
