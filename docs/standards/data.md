# 数据规范

- 表与字段 snake_case；业务实体含 id、created_at、updated_at，时间 UTC；作品相关实体有 user_id/work_id 可追溯归属。检查：迁移与数据模型测试。
- 迁移只新增文件，提供回退或向前修复步骤；正式剧情采纳原子写入，禁止部分成功。检查：失败注入和重复提交测试。
- 密钥为机密，材料/正文/角色记忆为私有，系统版本为公开。日志不含私有原文；备份同等级保护。
- 删除作品能力实现前必须定义业务库、向量、对象存储、缓存与备份的副本清单；活跃副本同步删除，备份按明确周期到期，不承诺即时擦除所有备份。保留期须在该能力规约中确定。
- 当前账号、会话、作品、幂等、模型配置、故事准备、持久任务及推演事件使用编号 SQL 迁移；pgvector 镜像仅准备检索能力，不声称已实现图谱或向量索引。检查：迁移合同测试与产品状态对应实际 schema。
