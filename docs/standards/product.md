# 产品设计规范

数值权威来源：[policy.json](../../config/policy.json)。本文件是长期约束，不表示所有业务已实现。例外见 [exceptions.md](exceptions.md)。

## P01 用户与场景
- 规则：README 按准备、观察、理解、管理、分享五项用户任务登记入口与完成结果，每个页面和能力关联任务。
- 检查：反查页面与任务映射。
- 违反时：补齐任务与可观察结果后合并。
- 启用阶段：M0 文档，M1 起界面
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P02 页面与信息架构
- 规则：固定侧栏工作台，背景、角色、讨论、回顾四区分别有 URL；全局新建、历史、说明；分享只读。刷新、前进后退可恢复；未知路由 404。
- 检查：逐路由直接访问与导航。
- 违反时：修正孤立、重复页面及丢失定位。
- 启用阶段：M1–M4
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P03 四种视图状态
- 规则：加载、正常、错误、空状态完备；未就绪分区仍可进入并说明下一步；局部失败保留已有内容，重连不清空发言。
- 检查：注入慢响应、错误和空数据。
- 违反时：修正白屏、无限加载或全局误清空。
- 启用阶段：M0 状态页，M1 起业务
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P04 文案与术语
- 规则：直白中文，少量英文档案标签；统一推演、虚拟角色、事件背景、轮次、发言、回复、过程回顾、我的推演。错误说明事情、原因与下一步。
- 检查：检索术语并走查失败提示。
- 违反时：统一用词，补可执行操作。
- 启用阶段：M0
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P05 表单与校验
- 规则：失焦与提交校验，错误紧邻字段并定位首项；生成抑制重复提交；背景角色自动保存并显示状态，失败保留输入；覆盖编辑先确认，Key 不自动保存。
- 检查：空值、边界、断网、重复点击。
- 违反时：修复丢失输入、重复创建或付费。
- 启用阶段：M1
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P06 视觉基线
- 规则：纸感档案风；公共组件与 CSS 变量集中维护。间距与字号见 policy.json；正文16px，复用按钮、卡片、状态、确认框，特殊样式登记。
- 检查：对照变量与公共组件。
- 违反时：复用或先扩展公共组件。
- 启用阶段：M0
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P07 可达性与响应式
- 规则：完整手机主流程；键盘可达、焦点可见、标签关联；文字对比度4.5:1、大字3:1；主要点击区44px；1024px以下抽屉；新发言不抢阅读位置。
- 检查：375/768/1280px、键盘及减少动效走查。
- 违反时：阻断无法完成任务、遮挡与不可达。
- 启用阶段：M0 基础，M1 起全流程
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P08 变更可追溯
- 规则：规约先于实现，规约、代码与验证同一 PR；导航和术语变化同步 README 及规范。
- 检查：反查变更、场景与验证。
- 违反时：补齐文档与证据。
- 启用阶段：M0
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P09 状态与流程
- 规则：后端转换状态；启动后快照固定；终结记录不改写。版本冲突保留输入并提示；失败复制配置新建；取消与完成原子判定。
- 检查：非法转换、同时取消完成、多标签保存。
- 违反时：修复静默覆盖与状态不一致。
- 启用阶段：M1–M3
- 例外：无；若正文含 EX 编号，以统一例外表为准。

## P10 导入导出
- 规则：一次一篇新闻，提取预览后确认；失败保留草稿，补充标用户提供；换背景须重确认角色。首版无附件、批量导入和文件导出。
- 检查：成功、失败、超限及覆盖测试。
- 违反时：阻断无确认覆盖与版本混用；导出不适用。
- 启用阶段：M1；导出暂不适用
- 例外：无；若正文含 EX 编号，以统一例外表为准。
