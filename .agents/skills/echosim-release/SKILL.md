# echosim-release

输入：版本、提交、镜像、目标环境。
1. 读 ops/data/security/review 与例外，确认本次实际启用能力。
2. 先完成可审查产物、门禁、适用真实冒烟、备份与回滚验证，整理版本记录。
3. 正式发布需维护者明确决定；不得因已有本地标签授权推断公网部署授权。缺少服务器域名则先列外部条件。
4. 授权目标上迁移先扩展、验证当前及上版兼容，新版本就绪后蓝绿切流，旧任务排空最多30s；失败切回上版，不自动破坏性降库。
5. 灾备恢复先隔离检查删除清单/过期规则/预算对账，再开放访问；不记录或上传秘密。
输出：版本、验证、批准范围、切换结果和回退目标；本地演练不得冒称生产部署。
