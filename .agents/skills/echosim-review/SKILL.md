# echosim-review

输入：仓库路径、变更名、基线。
1. 读 review.md 和相关规范，检查任务范围及最新差异。
2. 用户已授权临时独立审查子代理：仅传原始仓库/变更/基线与评审任务，不传预期结论。不得创建侧栏聊天。
3. 让审查者检查可复现缺陷、规则一致性、测试有效性和机密；给出文件位置、触发条件与影响。审查者只读，不运行真实模型，不修改他人代码。
4. 修复证实问题，重跑适用门禁。对未解决争议保持待决定，其余独立工作继续。
5. 常规已确认范围可在门禁与独立审查通过后Squash；新安全例外/预算增加/破坏数据/正式发布由维护者决定。
输出：发现、处理、最终提交、证据与未完成项。
